# Agetha Mod v5.7

Version 5.7 is a quality-of-life and defensive-hardening release for the
SiriusNovyx fork. It preserves existing AI providers, Fast Mode behavior,
command confirmations, protected-process rules, OCR target validation, and the
modular `agetha/` architecture.

## Highlights

- File drops validate size and file type locally, reject unsafe targets, and
  avoid exposing full local paths or sensitive file contents to providers.
- Explicit request-origin metadata separates direct user messages from touch,
  reminders, ambient polls, file drops, and tool results.
- External OCR, memory, web, document, notepad, and tool context passes through
  a centralized fail-closed redaction and truncation boundary.
- Tk work is marshalled to the main event loop, background workers are tracked,
  and late callbacks are discarded during shutdown.
- AI operations use synchronized ownership tokens so queued work cannot release
  or overwrite another active operation.
- Linux managed-window minimize failures restore stable UI state; Windows custom
  chrome and Surface/ARM64 behavior remain unchanged.
- Window-picker timeout, cancellation, grab release, and teardown are bounded.
- Malformed and unknown direct command payloads fail closed, and destructive
  command success is reported only after the underlying operation succeeds.

## Privacy and safety

This release does not weaken native confirmations, command tiers, protected
processes, OCR redaction, Fast Mode locks, or provider selection. Ordinary user
text that resembles an internal marker remains direct user input and does not
gain tool or deep-OCR authority.

## Validation

- Full unit suite: 509 tests passed, 8 skipped.
- Focused QOL/OCR/Fast Mode/web suite: 199 passed, 1 skipped.
- `python -m compileall agetha main.py`: passed.
- `git diff --check`: passed, with line-ending conversion warnings only.
- Automated real-Tk lifecycle smoke: passed.

The real Windows symlink test was skipped because the local account lacked
symlink-creation privilege; the deterministic mocked symlink-policy test passed.
No live paid-provider requests were used for validation.

## Remaining limitation

A provider network call may exceed the bounded shutdown join. Provider workers
remain daemonized and late UI callbacks are discarded, so application teardown
does not wait indefinitely.
