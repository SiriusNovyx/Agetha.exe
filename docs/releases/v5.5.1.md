# Agetha Mod v5.5.1

This fork release focuses on dependable screen context, Windows on ARM support,
high-DPI usability, expressive but guarded UI effects, and maintainability.

## Highlights

- Focused-window OCR now carries immutable capture geometry and identity through
  preprocessing, Tesseract extraction, pattern detection, and publication.
- Screen monitoring adds change detection, stale-window rejection, event
  confirmation/deduplication, capture exclusions, and outbound secret redaction.
- Optional Unlimited-OCR support provides an explicit deep-analysis command for
  complex documents and layouts. It is disabled by default and never used by
  ambient polling.
- Windows ARM setup distinguishes the native ARM64 host from an x64 Python
  process running under Prism, searches installed interpreters accurately, and
  repairs incompatible virtual environments.
- Companion and dashboard sizing now account for display resolution and DPI,
  including Surface-class 2880x1920 displays.
- Direct and ambient prompts receive compact local weekday, date, time, timezone
  name, and UTC-offset context across Groq, OpenRouter, and Ollama modes.
- A cancellable CRT close effect, optional mood glow, and centralized mood-motion
  controller respect dragging, minimize, geometry ownership, cooldown, closing,
  and reduced-motion settings.
- Graceful shutdown is centralized and idempotent across Tk jobs, voice, TTS,
  audio, OCR, tray, dashboard/children, and background stop events.
- The new `docs/` code map covers architecture, runtime flows, every module,
  configuration, Windows ARM behavior, and focused test selection.

## Safety and privacy

- Tesseract remains the local automatic OCR backend.
- Deep OCR requires an explicit user turn and Caution-tier confirmation before a
  screenshot can be sent.
- Remote deep-OCR servers require explicit opt-in.
- Screen and retrieved text remain labeled as untrusted AI context.
- Existing command gates, protected-process checks, confirmation tiers, and
  self-window protections remain intact.
- Reduced motion disables decorative movement and converts animated glow to a
  static border.

## Upgrade notes

1. Run `Medic_Checker.bat` after updating so the x64 interpreter, virtual
   environment, packages, Tesseract, assets, and configuration are checked.
2. Existing configuration remains compatible; missing settings use safe typed
   defaults.
3. Keep `DEEP_OCR_BACKEND = none` unless a separate Unlimited-OCR service has
   been configured intentionally.
4. Keep API keys in `.env`, never `config.txt`.
5. Use `UI_SCALE = auto` for high-DPI displays, or choose a manual value from
   `0.75` to `2.50`.
