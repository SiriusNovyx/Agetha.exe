## Requirements

* Python 3.13.x
* Tesseract OCR

### Install Python Dependencies

```bash
py -3.13 -m pip install pillow pyautogui pytesseract numpy pygame requests
```

### Install Tesseract OCR

Download and install Tesseract OCR:

https://github.com/UB-Mannheim/tesseract/wiki
